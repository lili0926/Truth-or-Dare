# 真心话 · 大冒险（卡牌版）

一个带**洗牌动画 + 抽卡 + 翻牌**的真心话大冒险网页小游戏。

卡背使用定制图片：
- 真心话：深酒红 + 金色火焰
- 大冒险：米白 + 心形锁

适合直接本地打开，也方便嵌进聊天页做成「抽卡插件」。

---

## 快速开始

1. 下载或克隆本仓库
2. 用浏览器直接打开 `index.html` 即可游玩
3. 无需安装任何依赖

```bash
# 如果用本地服务器（可选）
npx serve .
# 或
python -m http.server 8080
```

---

## 功能说明

| 功能 | 说明 |
|------|------|
| 模式切换 | 真心话 / 大冒险 |
| 洗牌 | 牌堆散开再收回的动画 |
| 抽卡 | 从对应题库随机抽取 |
| 翻牌 | 点击卡片翻转查看内容 |
| 关闭 | 点击空白处关闭当前卡 |

## 如何修改题库

打开 `index.html`，找到以下两个数组：

```js
const TRUTH_POOL = [ ... ]   // 真心话
const DARE_POOL  = [ ... ]   // 大冒险
```

直接增删改字符串即可，保存后刷新页面生效。

---

## 如何更换卡背图片

把新的图片放到 `assets/` 目录下，然后修改 `index.html` 里这两行：

```css
.back-truth {
  background: url('assets/你的真心话图.jpg') center/cover no-repeat;
}
.back-dare {
  background: url('assets/你的大冒险图.jpg') center/cover no-repeat;
}
```

建议图片比例接近 **2:3**（竖版卡牌）。

## 接入聊天页（简单思路）

1. 把抽卡逻辑抽成独立组件/函数
2. 用户或 AI 发起抽卡时，在聊天界面播放动画
3. 抽完后把结果（模式 + 内容）作为一条消息发送到聊天记录
4. 双方都能看到并回应

AI 没有实体时，大冒险内容可在发送前做一层「可执行化」处理（把实体动作改成文字描述/指令）。

## 自定义建议

- 调整洗牌幅度：修改 `shuffleDeck()` 里的随机位移和旋转数值
- 调整卡牌尺寸：改 `.card` 的 `width` / `height`
- 增加「混合抽」模式：抽卡时随机从两个池子里选
